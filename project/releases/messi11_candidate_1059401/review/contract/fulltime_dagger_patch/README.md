# Fulltime DAgger correction — 12시간 상한

## 실행

기존 패치가 설치된 MESSI 루트에서:

```bash
tar -xzf fulltime_dagger_patch.tar.gz
sbatch fulltime_dagger_patch/run.sbatch
```

gpu6 GPU 1개, CPU 4개, 메모리 32GB, Slurm 최대 12시간입니다.
내부 제한은 11시간 50분이며 작업을 완료하거나 악화 판정이 나면 일찍 종료합니다.

## 이번에 확인한 결과

기존 BC는 시드 7100/7101에서 0–23, 0–17, KL 후보는 0–25, 0–22였습니다.
모두 정규시간 5,400초를 완료했습니다. 합법 점유율은 0.0211%/0.0451%,
슛 실행은 4/2회였습니다. 슛 요청은 116,531/123,232회이며 이는 여러 선수의
요청을 누적한 값으로 실제 슛 횟수와 다릅니다. KL 후보를 채택하지 않습니다.

기존 시연 수집은 초기 8,192~16,384스텝이고, 이번 풀타임은 약 61,000~62,000스텝입니다.
경기 후반/점수/체력 상태와 학생이 실수한 뒤의 상태가 기존 시연에 충분히
포함되지 않았을 가능성이 있습니다. 이것이 유일한 원인이라고 검증된 것은 아닙니다.

## 새 학습

1. 기존 repaired BC로 실제 풀타임을 진행합니다(훈련 시드 8001).
2. 우리 팀은 학생 정책으로 행동합니다. 교사는 같은 관측에서 정답 행동만 제공합니다.
   상대 팀은 기존 규칙 기반 정책입니다. 학생의 잘못된 행동을 정답으로 저장하지 않습니다.
3. 활성 상태의 우리 팀 관측/교사 정답을 수집합니다. 두 번째 팀의 슬롯 순서를 섞지 않습니다.
4. 새 데이터 75%, 기존 시연 25%의 미니배치로 1,500회 supervised update를 수행합니다.
   라운드 2에서는 두 라운드의 학생 방문 데이터를 합칩니다.
5. 의도 클래스별 강제 균등 샘플링을 하지 않습니다. 실제 데이터 빈도로 샘플링합니다.
   MOVE의 body-aim 두 좌표는 계속 학습합니다. retouch guard는 정답과 학생에 적용됩니다.
6. 시드 7100/7101 풀타임 평가로 기존 BC와 비교합니다. 기존 BC 평가를 재사용합니다.
7. 득점 감소, 실점 증가, 점유 비율 80% 미만 또는 슛 감소 시 중단합니다.
   통과한 경우만 라운드 2(훈련 시드 8002)를 수행합니다. 최대 두 라운드입니다.

이는 기존 BC를 같은 데이터로 더 학습하는 실험과 달리 학생 방문 상태에서
교사 정답을 새로 수집하는 DAgger 방식입니다. PPO나 KL 손실은 사용하지 않습니다.
계수/LR/업데이트 수가 최적값이라고 검증된 것은 아닙니다. 실제 개선은 평가해야 합니다.

시드 7100/7101은 이제 모델 선택용 검증 시드입니다. 통과해도 별도 새 시드 평가가
필요하며 자동으로 배포 모델을 교체하지 않습니다. selected_checkpoint는 후보 경로입니다.
점유는 경기마다 다른 스텝 수를 고려해 비율로 비교합니다.

## 저장과 재개

기존 project 파일과 체크포인트는 수정하지 않습니다. 필요한 기존 소스 해시와
초기 actor 해시가 달라지면 중단합니다. 필요한 demo 파일이 없으면 시작 전에 중단합니다.
수집은 1,024스텝마다 저장, 학습은 100업데이트마다 저장, 평가는 기존 evaluator의
128스텝 저장을 사용합니다. 시간 제한 시 같은 sbatch 명령으로 재개할 수 있습니다.
이미 완료/악화 중단된 실험은 재제출해도 새로 학습하지 않습니다.
원시 데이터와 체크포인트는 서버에 남고, 전달용 결과에는 JSON/CSV/로그만 포함됩니다.

결과:
project/experiments/attack_fulltime_dagger_seed0/fulltime_dagger_results.tar.gz

진행 확인:
```bash
tail -F project/experiments/attack_fulltime_dagger_seed0/dagger_1.log
```

수집 중 COLLECT, 학습 중 FIT가 표시됩니다. 평가 로그는 eval_dagger_1_7100.log 등입니다.
서버의 실제 실행 시간은 미검증이며 12시간 내 완료를 보장하지 않습니다.

로컬 검증: 실제 환경 CPU JAX JIT 1스텝, 팀0 정답 마스킹, 종료 padding 제외, 유한한 학습 gradient를 확인했습니다. Mock runner에서 악화 중단·중복 실행 방지·2라운드 진행을 확인했습니다. 서버 전체 학습과 경기 성능 향상은 미검증입니다.
