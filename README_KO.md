# Overleaf 연구 제안 발표 초안

기존 결과·승률·로그·구현 완료 주장을 넣지 않은 10장 Beamer입니다.
발표의 RQ와 실험은 앞으로 수행할 계획입니다. 이미 검증했다는 의미가 아닙니다.

## 사용
Overleaf > New Project > Upload Project > 이 ZIP 업로드.
Compiler를 XeLaTeX로 지정하고 main.tex를 Recompile합니다.
한글 처리는 Overleaf TeX Live의 koTeX를 사용합니다.
로컬에는 kotex.sty가 없어 한글 PDF 컴파일/시각 검증은 수행하지 못했습니다.

## 제안한 연구질문
RQ1: 동일한 실행 관측과 보상에서 중앙 상태 기반 critic과 선수 관측 기반 critic 비교.
RQ2: 공통 shaping과 역할·소유 조건별 shaping 비교.
네 비교군 A/B/C/D와 최소 3개 학습 시드를 계획합니다.
이 설계는 기존 진행 실험을 그대로 소급해 네 비교군으로 분류하는 것이 아닙니다.

## 발표 전에 확정할 설계
- MESSI 관측은 full-information입니다. 따라서 RQ1을 '가려진 정보를
  중앙 critic만 얻는 실험'이라고 설명하지 않습니다. 중앙 상태 인코딩 대
  선수 중심 관측 인코딩이라는 표현/critic 구성 비교입니다.
- 두 critic 모두 동일한 선수/역할별 학습 target과 집계 가중치를 쓰고,
  가능하면 per-agent value head로 맞춥니다. 중앙 critic만 역할 평균 target을
  쓰면 표현 효과와 target 집계 효과가 섞입니다. 이 비교 경로는 새 구현이 필요합니다.
- 역할별 shaping에서는 필드와 GK의 학습 목적이 달라집니다. 공통 팀 보상의
  표준 MAPPO와 구분해 'PPO 기반 역할별 보상 변형'이라고 부릅니다.
- 공통 shaping 조건은 동일한 필드/GK 보상 성분을 팀 수준으로 합쳐 공유하고,
  역할 조건은 해당 성분을 필드/GK에 배분합니다. 계수와 스케일을 예비실험에서
  고정합니다. 이 비교는 역할별 설계 전체의 효과이며 계수 하나의 효과가 아닙니다.
- 모든 조건의 Actor 정책 구조, 합법성 처리, 규칙 대형 보조와 GK 이동 변환을
  동일하게 유지합니다. 강한 GK 제약은 보상의 추가 효과를 가릴 수 있으므로
  연속 위치 지표와 field 행동도 함께 봅니다. 정책 제약을 동시에 바꾸지 않습니다.
- 순수 규칙 정책은 별도 무학습 참고 기준으로 둘 수 있습니다. 규칙 기여를
  PPO 기여로 설명하지 않습니다. 과제의 규칙 보조 허용 여부는 별도 확인합니다.
- BC는 본 비교에서 사용하지 않는 안입니다. 동일 무작위 Actor 초기화로 시작해
  학습량을 맞춥니다. warm start 사용 시 모든 조건에 동일하게 적용하고 명시합니다.
- 최소 3개 학습 시드가 추정 정밀도를 보장하지는 않습니다. 시드별 결과와
  불확실성을 보고하고 경기 수만 늘려 독립 학습 반복처럼 취급하지 않습니다.
- 훈련 상대 풀은 네 조건에 동일하게 고정합니다. 상대 풀 다양성은 이번 RQ의
  추가 실험 요인이 아닙니다. held-out 학생 팀은 확보했을 때만 평가합니다.
- 세부 계수, 학습 스텝 예산, 평가 경기 수, 분산/신뢰구간 보고 방법은
  짧은 속도 측정과 계산 예산에 맞춰 사전 확정합니다. 새 Slurm 작업은 제출하지 않습니다.

## 참고문헌의 역할
Yu et al. (2022), Sec.3.2: MAPPO/IPPO의 value 입력 구분.
Amato (2024), Sec.2 및 4: CTDE와 중앙 critic의 개념 및 해석상 주의점.
역할별 보상 RQ는 위 논문의 입증 결과가 아닌 본 프로젝트의 제안입니다.
두 논문을 MESSI에서의 알고리즘 우열 근거로 쓰지 않습니다.
